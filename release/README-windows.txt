Decorator 0.1.0 for Windows (64-bit)

VST3: copy the  Decorator.vst3  folder to  C:\Program Files\Common Files\VST3\
      then restart your DAW and rescan plugins if it asks.
App:  Decorator.exe runs on its own (choose your audio interface in its settings).

If Windows SmartScreen warns about an unknown publisher, click "More info" -> "Run anyway".
The files are not code-signed.

Set "Interface dBu" at the bottom of the plugin to your audio interface's input level at 0 dBFS
(12.5 for a Focusrite Scarlett 3rd Gen instrument input at minimum gain).

Source and help: https://github.com/alejandrozarco/decorator
